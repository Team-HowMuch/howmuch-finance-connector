3. 인증 확인 및 최종 동의

QR 연결 후 PC 앱에서 우리은행과 HowMuch LOCAL MOCK ONLY 인증서를 선택하세요. 인증서 암호는 test1234!, 가상 계좌번호는 1002123456789, 계좌 비밀번호는 1234입니다. 인증 완료 후 연결 상태를 새로 확인하세요.

금융사 인증 완료 후 승인 요청을 누르면 확인 코드가 나타납니다.

4. 연결 목록과 계좌 조회


        
PIN은 로그인 요청 후 지우고, Access Token과 QR 값은 브라우저 저장소나 로그에 기록하지 않습니다. 연결 API 요청 시 로컬 API로만 전달합니다. 초기 QR 연결 후 최종 YES를 눌러야 금융사 연결이 사용자에게 저장됩니다. CODEF mock은 실제 인증서 암호를 검증하지 않습니다.
